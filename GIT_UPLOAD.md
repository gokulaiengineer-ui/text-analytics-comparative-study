# Upload to GitHub
1. Create an empty repository on github.com (e.g. `text-analytics-library-comparison`), no README.
2. In a terminal inside this folder:
```bash
git init
git add .
git commit -m "Text analytics term project: NLTK vs spaCy vs CoreNLP"
git branch -M main
git remote add origin https://github.com/<your-username>/text-analytics-library-comparison.git
git push -u origin main
```
3. Share the repository link with your department.
